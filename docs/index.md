# Правила «Повелителя Тайн»

Рабочий перевод китайской настольной ролевой игры. Для поиска по книге нажмите **«Поиск»** вверху страницы. В главах есть спойлеры за пределами первого тома.

## Начать игру

- [Предисловие](/book/chapter-01) — как пользоваться правилами.
- [Проверки](/book/chapter-02), [характеристики](/book/chapter-03) и [навыки](/book/chapter-04) — основа системы.
- [Стать Потусторонним](/book/chapter-05) и [бой](/book/chapter-06) — создание и действия персонажа.
