# Сопоставление исправлений Путей

Скрипт обрабатывает журналы v17–v33 и дополнительные явно указанные журналы. Изменения допускаются только для адресов, вручную проверенных в `sync-approved-paragraphs.json`. В `sync-reviewed-rulings.json` перечислены отдельно проверенные исключения для адресов из реестра разночтений. Эти списки нельзя пополнять автоматически: проверяйте смысл, терминологию сайта, оригинал и контекст.

По умолчанию скрипт ничего не меняет. Он проверяет старый и новый фрагмент; если старый встречается многократно, допускает замену на строке из журнала при совпадении позиции со снимком. Эти проверки не подтверждают правильность перевода. Статус «already present» не доказывает её: короткий фрагмент мог встретиться в другом месте. Отчёт сохраняйте вне сайта, поскольку он содержит рабочие фрагменты.

```powershell
python tools/sync-reviewed-paths.py --source "D:/Files/НРИ/lotm-foundry-ru/local-content" --rulings "D:/Files/НРИ/lotm-foundry-ru/docs/TRANSLATION_RULINGS.md" --snapshot "D:/Files/НРИ/lotm-foundry-ru/local-content/book-v33-path-sources-20261123" --approved tools/sync-approved-paragraphs.json --reviewed-rulings tools/sync-reviewed-rulings.json --report "D:/Files/НРИ/lotm-sync-report.json"
```

Добавьте `--apply` для записи и проверьте `git diff`. Для v34 и следующих укажите новый снимок через `--snapshot` и каждый новый журнал через `--extra-review "полный/путь/к/журналу.json=17"`, где 17 — номер файла `chapter-10-17.md`. Новые адреса предварительно разбирают и вручную вносят в списки. Несовпадения и спорные трактовки остаются в отчёте.

Ранние v14–v16 без однотипных журналов перенесены отдельной сверкой снимков: два изменения в главе 10-01 и два в 10-03. Журналы v6–v13 относятся к общим главам и требуют отдельного сопоставления.
