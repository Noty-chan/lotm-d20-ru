# Читалка правил «Повелитель Тайн»

Это снимок рабочего перевода на момент экспорта. Он содержит главы 1–11, включая поздние спойлеры. Обновление основного перевода автоматически не попадает в эту копию.

## Запуск

Установите Node.js 20, затем выполните npm ci и npm run dev. Поиск локальный; открытую страницу можно сохранить в PDF через Ctrl+P.

## GitHub Pages

Сайт GitHub Pages обычно доступен всем в интернете, включая содержимое страниц и перевода. Сначала проверьте состав материалов. Поместите только содержимое этой папки в отдельный репозиторий, включите GitHub Pages с источником GitHub Actions и вручную запустите workflow Publish GitHub Pages. Сборка проверяет внутренние ссылки; при неработающей ссылке публикация не происходит. Путь настраивается переменной READER_BASE. Для сайта вида username.github.io следует использовать / вместо имени репозитория.

## Обновление

Создайте новый изолированный экспорт из рабочего проекта и обновите только файлы этой копии после проверки содержимого.
